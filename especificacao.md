# Contexto
Você é um Desenvolvedor Front-End Sênior e Educador especialista em criar ferramentas interativas de aprendizado. Sua tarefa é desenvolver o código completo (HTML, CSS e JavaScript puro) de um jogo da memória educativo sobre Arquitetura Computacional para estudantes universitários.

## Termos e Conceitos Obrigatórios (para os cards de explicação)
1. CPU, 2. ULA, 3. UC (Unidade de Controle), 4. Registradores, 5. RAM, 6. ROM, 7. EEPROM, 8. Flash, 9. Cache, 10. Memória de massa (armazenamento), 11. DMA, 12. Address Bus (Barramento de endereço).

## Objetivo
Criar um jogo da memória funcional e bem explicativo onde o usuário relaciona cards de "Nome do Termo" com cards de "Explicação do Conceito". O design deve ser objetivo, responsivo e incentivar os estudos.

## Escopo Técnico e Restrições
- **Tecnologias:** Apenas HTML5, CSS3 e JavaScript (sem frameworks externos).
- **Restrições de JS:** Utilizar apenas estruturas de repetição, condicionais, vetores, objetos, manipulação do DOM, classes/IDs/pseudoclasses CSS. A única função nativa permitida do JS é `Math.random()`.
- **Fora do escopo:** Conteúdos externos ao contexto ou bibliotecas de terceiros.

## Funcionalidades e Regras
1. Tela inicial para iniciar o jogo.
2. Seleção de cards com animação de virada.
3. Contador de acertos, erros e tempo de jogo.
4. Tela de conclusão exibindo o tempo, pontuação e uma seção com a explicação detalhada de todos os termos estudados para reforçar o aprendizado.

## Formato de Entrega
Forneça o código limpo, comentado e estruturado com os arquivos de HTML, CSS e JavaScript separados.

## Limites e Restrições
- **Proibido uso de bibliotecas externas:** Não inclua React, Vue, jQuery, Bootstrap, Tailwind ou qualquer framework/biblioteca de terceiros. Apenas HTML, CSS e JS puro.
- **Proibido funções avançadas de JS:** É estritamente proibido o uso de métodos modernos complexos (como `fetch`, `async/await`, `Map`, `Set`, `Array.prototype.reduce/map/filter`, etc.). Siga estritamente a lista de recursos permitidos.
- **Foco absoluto na entrega:** Não adicione explicações teóricas curtas e sem profundidade nem fora do código solicitado.
- **Obrigatoriedade dos termos:** Todos os 12 termos listados na seção de contexto devem aparecer obrigatoriamente nas explicações do jogo.
